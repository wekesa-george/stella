# Download Exchange Logos

## Quick Download Instructions

Visit the following URLs and download the PNG logos (200x200 or 512x512 size):

### 1. Binance
- URL: https://cryptologos.cc/binance
- Click "Download PNG" button
- Save as: `public/exchanges/binance.png`

### 2. Bybit
- URL: https://cryptologos.cc/bybit
- Click "Download PNG" button
- Save as: `public/exchanges/bybit.png`

### 3. OKX
- URL: https://cryptologos.cc/okx
- Click "Download PNG" button
- Save as: `public/exchanges/okx.png`

### 4. Kraken
- URL: https://cryptologos.cc/kraken
- Click "Download PNG" button
- Save as: `public/exchanges/kraken.png`

### 5. KuCoin
- URL: https://cryptologos.cc/kucoin
- Click "Download PNG" button
- Save as: `public/exchanges/kucoin.png`

### 6. Binance Testnet (Optional)
- You can reuse the Binance logo or create a variant
- If reusing, copy `binance.png` to `binance_t.png`

## Alternative Download Method

You can also use these alternative sources:

1. **Brandfetch** - Visit https://brandfetch.com/ and search for each exchange
2. **Official Exchange Websites** - Most exchanges have press kits with logos
3. **CoinGecko** - https://www.coingecko.com/ has exchange logos in their API

## After Downloading

Once you've downloaded all logos to `public/exchanges/`, the app will automatically display them instead of the initials. The code includes a fallback to show initials if a logo is not found.

## File Requirements

- Format: PNG with transparent background
- Size: 200x200 or 512x512 pixels (square)
- Naming: lowercase exchange ID (e.g., `binance.png`, `bybit.png`)
