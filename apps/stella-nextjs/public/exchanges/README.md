# Exchange Logos

This folder contains logos for cryptocurrency exchanges used in the application.

## Required Logos

Download the following logos from https://cryptologos.cc/ (PNG format, 200x200 or 512x512):

1. **Binance**: https://cryptologos.cc/binance → Save as `binance.png`
2. **Bybit**: https://cryptologos.cc/bybit → Save as `bybit.png`
3. **OKX**: https://cryptologos.cc/okx → Save as `okx.png`
4. **Kraken**: https://cryptologos.cc/kraken → Save as `kraken.png`
5. **KuCoin**: https://cryptologos.cc/kucoin → Save as `kucoin.png`

## File Naming Convention

All logo files should be:
- Lowercase exchange ID (matching the `id` field in EXCHANGES_DATA)
- PNG format with transparent background
- Square aspect ratio (recommended 200x200 or 512x512)
- Named as: `{exchange-id}.png`

Example: `binance.png`, `bybit.png`, etc.
